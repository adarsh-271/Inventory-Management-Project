# AvenueMart Inventory Optimization Dashboard

An Excel analytics project analysing inventory, stockouts, supplier performance and inventory losses for a fictional retail business.

## Project Overview
Analysed 20 months of data across 250 products, 40 suppliers and 4 warehouses to identify excess inventory and improve replenishment decisions.

## Tools Used
Microsoft Excel | Power Query | Power Pivot | DAX | PivotTables

## Key Features
- Cleaned and integrated 9 datasets containing 45,000+ operational records.
- Built a data model with 16 relationships and 56 DAX measures.
- Developed an interactive dashboard with 12 KPI cards and 8 PivotCharts.
- Added Warehouse, Category and ABC Class slicers.
- Validated 18 headline KPIs against project benchmarks.

## Key Findings
| Metric | Result |
|---|---:|
| Current Inventory Value | ₹37.85 crore |
| Above-Target Inventory | ₹14.00 crore |
| Current Stockout Product–Warehouse Pairs | 321 |
| Slow-Moving Inventory Value | ₹4.25 crore |
| Unfulfilled Demand | 41,962 units |
| Supplier On-Time Delivery | 80.6% |
| Supplier Fill Rate | 91.1% |

Current inventory figures are as of 31 August 2026.
Study period: January 2025–August 2026.

## Recommendations
- Reallocate stock between warehouses to address shortages.
- Reduce purchasing for products exceeding target stock.
- Prioritise replenishment of high-demand products.
- Review slow-moving inventory and supplier reliability.
